# YouTube Ad Auto Skip

個人利用を想定した Chrome Manifest V3 拡張機能です。

## インストール
1. ZIPを展開します。
2. Chrome の `chrome://extensions` を開きます。
3. 右上の「デベロッパーモード」を有効にします。
4. 「パッケージ化されていない拡張機能を読み込む」をクリックし、展開した `youtube-auto-skip` フォルダを選びます。
5. YouTubeのページを再読み込みします。

## 使い方
Chrome の拡張機能アイコンから ON/OFF を切り替えられます。初期状態は ON です。

表示中の YouTube タブだけで動作します。`button.click()` の合成イベントが無視される場合に対応するため、`debugger` 権限を使って Chrome からマウス入力を送ります。動作時には Chrome のデバッグ通知が表示されます。クリック処理が終わると接続を解除します。

YouTube タブで開発者ツールを開いている場合、デバッガーの接続が競合することがあります。動作確認時は開発者ツールを閉じてください。

## 更新後・動かない場合
1. Chrome の `chrome://extensions` で、この拡張機能の再読み込みボタンを押します。
   この拡張機能は `debugger` 権限を使用します。権限の確認が表示されたら承認し、拡張機能が有効になっていることを確認してください。
2. 開いている YouTube のページも再読み込みします。拡張機能だけを更新しても、開いているページのスクリプトは更新されません。
3. 拡張機能の「自動スキップを有効化」が ON になっていることを確認します。
4. スキップボタンが表示される広告で確認します。ボタンが出ない広告は対象外です。

## 開発時の確認
Node.js がある環境では `node --test *.test.cjs` でボタン検出、ON/OFF、デバッガー入力処理のテストを実行できます。実際の YouTube 広告での動作確認は別途必要です。

## バージョンの更新方針

拡張機能をリリースする際は、`manifest.json` の `version` を `メジャー.マイナー.パッチ` の形式で更新します。

- 不具合修正: パッチを上げます（例: `1.0.0` → `1.0.1`）。
- 既存の動作と互換性のある機能追加: マイナーを上げ、パッチを `0` に戻します（例: `1.0.1` → `1.1.0`）。
- 互換性のない変更: メジャーを上げ、マイナーとパッチを `0` に戻します（例: `1.1.0` → `2.0.0`）。

公開・配布済みのバージョンより必ず大きい番号にし、同じ番号の再利用や巻き戻しは行いません。コミットごとに上げる必要はなく、README などのドキュメントのみの変更では更新不要です。

リリース時は、動作確認を済ませ、バージョン変更をリリース対象の修正と一緒にコミット・push します。

## 注意
- スキップボタンが表示された広告のみ対象です。広告の通信遮断・強制シークは行いません。
- YouTubeのUI変更で動作しなくなる可能性があります。
- YouTubeの利用規約や運用上の扱いについて、動作や適合性を保証するものではありません。
